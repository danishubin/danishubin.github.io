# Daniel Shubin portfolio

A buildless portfolio refreshed from the November 2026 CV. Open index.html directly or run python -m http.server 8000 from the repository and visit /portfolio/.

The homepage uses css/pixel.css and js/pixel.js. Existing gallery, chess, and other legacy pages retain their original styles. The root homepage redirects to /portfolio/.

The transparent pixel portrait was prepared with the built-in imagegen tool from the supplied reference. Prompt: remove the white background; preserve the person, pose, green shirt, plaid jacket, black outlines, and pixel style; add no text or objects.

Resume download: resume.docx. Content is based on the supplied CV; no contact telephone number is displayed on the page. Google Fonts enhance typography; local monospace and sans-serif fallbacks work offline.
